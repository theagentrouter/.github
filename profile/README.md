## From laptop to production

Try it with one command on your laptop. Ship the same configuration on Kubernetes — no rewrite in between.

```shell
OPENAI_API_KEY=sk-... aigw run
```

Then point anything OpenAI-compatible at `http://localhost:1975/v1`. → [CLI guide](https://theagentrouter.ai/docs/cli/aigwrun) · [Kubernetes guide](https://theagentrouter.ai/docs/getting-started/)
